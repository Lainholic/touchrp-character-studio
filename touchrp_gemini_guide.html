TouchRP · 사전 준비

플레이 전, 키 하나만 발급받으면 끝나요

TouchRP는 중앙 서버 없이 당신의 기기에서 직접 AI와 대화해요. 무료 Gemini API 키가 하나 필요합니다 — 아래 4단계, 3분이면 끝납니다.

1

Google AI Studio 접속

평소 쓰시는 구글 계정으로 로그인하면 됩니다. 별도 가입이 필요 없습니다.

aistudio.google.com 열기
2

약관 동의 (최초 방문 시)

처음 접속하면 이용 약관 동의 창이 한 번 뜹니다. 동의하고 넘어가면 이후에는 다시 뜨지 않습니다.

3

"Create API key" 클릭

화면의 Create API key 버튼을 누르면 프로젝트 선택 창이 뜹니다. 기본으로 뜨는 프로젝트를 그대로 선택하고 키 생성을 완료하세요.

생성된 키는 안전하게 암호화되어 로컬에만 저장됩니다.
4

키 복사 → TouchRP에 붙여넣기

생성된 키를 복사한 뒤, TouchRP 우측 상단 [AI 연동] 메뉴의 API 키 칸에 붙여넣고 저장하세요.

🔒 발급된 API 키는 본인의 PC 로컬에만 저장되며 외부 서버로 전송되지 않습니다.
