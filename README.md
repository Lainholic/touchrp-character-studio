## 💡 실리태번(SillyTavern) 유저들을 위한 활용법
- **터치 부위를 지정하지 않아도 됩니다!**
- AI로 뽑은 캐릭터 일러스트를 올려서 **[🪄 원클릭 외곽 흰색 지우기]**와 **[🎯 스팟 지우개]**로 배경을 깔끔하게 날린 후, **`[📥 실리태번용 투명 PNG 저장]`** 버튼을 누르면 실리태번 아바타로 바로 쓸 수 있는 고화질 투명 PNG가 즉시 저장됩니다.
- 캐릭터 이름과 시나리오를 적고 터치 부위까지 지정하면, **터치RP 본체에서 터치 인터랙션과 실시간 반응**까지 모두 즐기실 수 있습니다!

## 🇰🇷 한국어
> **"완벽한 전문 그래픽 툴은 아니지만, 브라우저에서 10초 만에 흰옷 안 파먹고 누끼 따서 실리태번 아바타와 터치 카드를 만드는 가벼운 무료 툴입니다."**

### ⚡ 빠른 사용 방법
1. 상단의 **[🌐 웹에서 설치없이 바로 실행하기]** 버튼을 누르거나, HTML 파일을 다운로드하여 더블클릭합니다.
2. 스탠딩 이미지를 화면으로 끌어다 넣고 **[🪄 원클릭 외곽 흰색 지우기]**를 누르면 끝!
3. 다리 사이나 팔 틈새는 **[🎯 스팟 지우개]**로 콕 찍어 시원하게 뚫어줍니다.
4. **실리태번 아바타로만 쓸 경우**: `[📥 실리태번용 투명 PNG 저장]` 클릭!
5. **터치RP 카드까지 만들 경우**: 신체 부위를 마우스로 드래그하여 터치 영역을 지정하고 `[💾 완성 팩 저장]` 클릭!
